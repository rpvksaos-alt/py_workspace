과제. 학생 성적 관리 프로그램

1) 프로그램 요구사항
학생 이름과 과목별 점수를 관리하고, 성적을 분석한 후 파일로 저장하고 불러오는 프로그램을 작성합니다.

1. 학생 등록
2. 전체 학생 성적 조회
3. 학생별 평균 및 등급 조회
4. 최고점·최저점 학생 조회
5. 평균 이상 학생 조회
6. 성적 파일 저장
7. 성적 파일 불러오기
0. 종료

2) 학생 데이터 구조 예시

학생 한 명의 정보는 딕셔너리로 관리하고, 여러 학생은 리스트에 저장합니다.

students = [
    {
        "name": "김민수",
        "scores": {
            "국어": 85,
            "영어": 90,
            "수학": 78
        }
    },
    {
        "name": "이서연",
        "scores": {
            "국어": 95,
            "영어": 88,
            "수학": 92
        }
    },
    {
        "name": "박지훈",
        "scores": {
            "국어": 70,
            "영어": 75,
            "수학": 80
        }
    }
]

3) 필수 구현 기능

1. 학생 등록

add_student()

- 학생 이름을 입력받습니다.
- 국어, 영어, 수학 점수를 입력받습니다.
- 입력한 정보를 딕셔너리로 만들어 students 리스트에 추가합니다.
- 점수는 0점 이상 100점 이하만 허용합니다.
- 이미 등록된 이름이라면 중복 등록을 방지합니다.

2. 전체 학생 성적 조회

show_students()

등록된 학생의 이름과 세 과목 점수를 모두 출력합니다.

3. 학생별 평균과 등급 계산

get_average()
get_grade()

- 각 학생의 세 과목 평균을 계산합니다.
- 평균에 따라 등급을 부여합니다.
- 평균은 소수점 둘째 자리까지 출력합니다.

4. 최고점·최저점 학생 찾기
- 학생별 세 과목 평균을 기준으로 최고점 학생을 찾습니다.
- 최저점 학생도 찾습니다.
- 동점자가 있다면 해당 학생을 모두 출력합니다.

5. 평균 이상 학생 조회
- 전체 학생의 평균 점수를 계산합니다.
- 전체 평균 이상인 학생의 이름과 개인 평균을 출력합니다.
- 학생이 한 명도 없다면 적절한 안내 메시지를 출력합니다.

6. 성적 파일 저장
save_students()
1. students.txt 파일을 생성합니다.
2. 학생 정보를 한 줄씩 저장합니다.
3. 각 항목은 쉼표(,)로 구분합니다.
4. 한글이 깨지지 않도록 encoding="utf-8"을 지정합니다.
5. 저장 완료 메시지를 출력합니다.
